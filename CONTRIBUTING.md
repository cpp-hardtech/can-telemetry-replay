# Contributing

## Workflow

1. Open an issue to discuss substantial changes.
2. Create a topic branch and keep each pull request focused on one change.
3. Build and run the CTest suite using the commands in [README.md](README.md).
4. Describe the change and verification in the pull request.

Match surrounding formatting. Use fixed timestamps and small local fixtures when
adding replay tests so they run without a CAN device.
